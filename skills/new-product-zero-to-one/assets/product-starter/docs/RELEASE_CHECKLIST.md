# Release Checklist

## Pre-Release

- [ ] Product scope confirmed.
- [ ] Design changes reviewed.
- [ ] Architecture-impacting changes documented.
- [ ] Tests pass.
- [ ] Typecheck passes.
- [ ] Lint passes.
- [ ] Build passes.
- [ ] Security-sensitive config reviewed.
- [ ] Environment target confirmed.

## Manual QA

- [ ] First open.
- [ ] Primary flow.
- [ ] Empty state.
- [ ] Error state.
- [ ] Returning user.
- [ ] Permissions.
- [ ] Mobile/responsive behavior.

## Release

- [ ] Version noted.
- [ ] Release notes written.
- [ ] Deployment completed.
- [ ] Production smoke test completed.

## Post-Release

- [ ] Logs checked.
- [ ] Known issues recorded.
- [ ] Docs synced.
